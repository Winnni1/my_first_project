# Ответы на вопросы для самоконтроля

## 1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?

Основное свойство — `display: grid` (или `display: inline-grid`). Оно превращает элемент в **grid-контейнер**, а его прямые дочерние элементы — в **grid-элементы**, которые размещаются в двумерной сетке.

**Отличие от Flexbox:** Flexbox — это одномерная модель (элементы выстраиваются вдоль одной оси — строки или колонки). CSS Grid — двумерная модель: одновременно управляет и строками, и колонками, позволяет размещать элементы в явно заданных ячейках и областях. Flexbox лучше подходит для выравнивания элементов в линию, Grid — для построения целостных макетов страниц.

## 2. В чем разница между grid-template-columns и grid-auto-columns? Когда следует использовать каждое?

- `grid-template-columns` задаёт **явную** структуру колонок сетки — сколько их и какого размера.
- `grid-auto-columns` задаёт размер **неявных** колонок, которые создаются автоматически, когда элемент размещается за пределами явно заданной сетки (например, при `grid-column: 5`, если явно задано только 3 колонки).

`grid-template-columns` используется для основного каркаса макета. `grid-auto-columns` — когда количество элементов заранее неизвестно или элементы выходят за пределы явной сетки, и нужно контролировать размер автоматически создаваемых дорожек.

## 3. Что делают функции repeat(), minmax() и auto-fit в определении grid-шаблона? Приведите примеры.

- `repeat(n, size)` — повторяет указанный размер `n` раз. Пример: `grid-template-columns: repeat(4, 1fr)` создаёт 4 равные колонки.
- `minmax(min, max)` — задаёт диапазон размера дорожки: не меньше `min` и не больше `max`. Пример: `minmax(200px, 1fr)` — колонка не уже 200px, но может растягиваться.
- `auto-fit` (внутри `repeat`) — автоматически создаёт столько колонок, сколько помещается, и **растягивает** их, заполняя свободное пространство.

**Пример адаптивной галереи:**
```css
.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 1rem;
}
```
Колонки автоматически подстраиваются под ширину контейнера, но не становятся уже 250px.

## 4. Как работают именованные grid-области и какие преимущества они дают при создании макетов?

Именованные области задаются через `grid-template-areas`, где строки описываются строками-строками с именами ячеек. Элементы привязываются к области свойством `grid-area: имя`.

**Преимущества:**
- Макет визуально читается прямо в CSS — видно структуру страницы.
- Легко переставлять блоки, меняя только шаблон.
- Удобно адаптировать под мобильные устройства, переопределяя `grid-template-areas` в медиа-запросе.
- Не нужно высчитывать номера линий.

**Пример:**
```css
.grid-container {
    display: grid;
    grid-template-areas:
        "header header"
        "nav main"
        "sidebar footer";
}
.header { grid-area: header; }
```

## 5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.

Линии сетки нумеруются, начиная с **1**, слева направо (для колонок) и сверху вниз (для строк). Отрицательные номера (`-1`, `-2`...) отсчитываются от конца сетки.

Свойства `grid-column` и `grid-row` задают положение элемента по линиям:
- `grid-column: 2 / 4` — элемент начинается со 2-й линии и заканчивается перед 4-й (занимает 2 колонки).
- `grid-row: 1 / 3` — занимает две строки.
- Можно использовать `span`: `grid-column: span 2` — растянуть на 2 колонки.

**Пример:**
```css
.gallery-item:nth-child(1) {
    grid-area: 1 / 1 / 2 / 2; /* строка 1 / колонка 1 / строка 2 / колонка 2 */
}
```

## 6. Что такое grid-gap (или gap) и чем он лучше margins для создания промежутков в сетке?

`gap` (ранее `grid-gap`) задаёт промежутки между строками и колонками grid-сетки: `gap: 1rem` или `row-gap` / `column-gap` отдельно.

**Преимущества перед margin:**
- Не нужно задавать отступы каждому элементу и компенсировать их у краёв.
- Промежутки создаются **только между** элементами, а не по внешним краям контейнера.
- Работает одинаково для строк и колонок.
- Проще поддерживать: одно значение меняет всю сетку.
- Нет конфликтов при переносе и перестроении сетки в медиа-запросах.

## 7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?

- `justify-items` выравнивает содержимое каждого grid-элемента вдоль **inline-оси** (обычно горизонтально) внутри его ячейки.
- `align-items` выравнивает содержимое вдоль **block-оси** (обычно вертикально) внутри ячейки.

Значения: `start`, `end`, `center`, `stretch` (по умолчанию). Они применяются ко всем элементам сетки; для отдельного элемента можно переопределить через `justify-self` / `align-self`.

**Пример:** `align-items: center` — все элементы центрируются по вертикали в своих ячейках.

## 8. В чем разница между auto-fill и auto-fit при создании адаптивных сеток?

Обе функции используются внутри `repeat()` для автоматического создания колонок. Разница — в поведении при **нехватке элементов**:
- `auto-fill` создаёт максимально возможное количество колонок, даже если элементов меньше. Пустые колонки сохраняются, элементы не растягиваются.
- `auto-fit` создаёт колонки по количеству элементов и **схлопывает** пустые дорожки, позволяя существующим элементам растягиваться на освободившееся пространство.

**Пример:** при 2 элементах и ширине, вмещающей 4 колонки, `auto-fill` оставит 4 колонки (2 пустые), а `auto-fit` сделает 2 широкие колонки.

## 9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования областей существуют?

`grid-template-areas` описывает макет строками, где каждая строка — строка сетки, а имена ячеек задают области.

**Правила именования:**
- Имя области — произвольный идентификатор (без пробелов).
- Одинаковое имя в соседних ячейках объединяет их в одну прямоугольную область.
- Область должна быть **прямоугольной** — нельзя делать Г-образные или разрывные области.
- Точка `.` обозначает пустую ячейку.
- Каждая строка шаблона должна содержать одинаковое количество ячеек.

**Пример:**
```css
.grid-container {
    grid-template-areas:
        "header header header"
        "nav main sidebar"
        "footer footer footer";
}
.header { grid-area: header; }
```
Элемент привязывается к области через `grid-area: имя`.

## 10. Какие преимущества дает CSS Grid перед другими методами верстки для создания сложных двумерных макетов?

- **Двумерность:** одновременное управление строками и колонками, чего нет у Flexbox и float.
- **Читаемость:** `grid-template-areas` делает макет наглядным прямо в CSS.
- **Гибкость:** функции `repeat()`, `minmax()`, `auto-fit`/`auto-fill` позволяют создавать адаптивные сетки без медиа-запросов.
- **Точное размещение:** элементы можно ставить в конкретные ячейки и растягивать на несколько дорожек (`span`).
- **Меньше обёрток:** не нужны дополнительные контейнеры и хаки с `clearfix`.
- **Управление промежутками:** `gap` работает предсказуемо.
- **Совместимость с Flexbox:** Grid задаёт общий каркас страницы, а Flexbox — выравнивание внутри отдельных блоков. Вместе они дают максимальную гибкость.
