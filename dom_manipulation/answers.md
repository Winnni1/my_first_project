# Ответы на вопросы для самоконтроля

1. **В чем разница между `innerHTML` и `textContent` и когда следует использовать каждый метод?**  
   `innerHTML` читает или устанавливает HTML-разметку внутри элемента и при присваивании строки браузер разбирает её как HTML. `textContent` работает с обычным текстом и не интерпретирует разметку. Для вывода пользовательского текста предпочтительнее `textContent`, так как это безопаснее и не позволяет случайно вставить HTML или скрипт.

2. **Как работает делегирование событий и какие преимущества оно дает при работе с динамическими элементами?**  
   Обработчик устанавливается на общего родителя, а при возникновении события проверяется его `target` и при необходимости ближайший подходящий элемент. Это позволяет обрабатывать элементы, созданные позже, без установки отдельного обработчика на каждый из них, и уменьшает количество обработчиков.

3. **Какие методы используются для поиска элементов в DOM и в чем разница между `getElementById`, `querySelector` и `querySelectorAll`?**  
   `getElementById` ищет элемент с указанным ID. `querySelector` принимает CSS-селектор и возвращает первый совпавший элемент или `null`. `querySelectorAll` возвращает статический `NodeList` всех совпадений с CSS-селектором.

4. **Как предотвратить стандартное поведение элемента при обработке событий и когда это необходимо?**  
   Для этого вызывают `event.preventDefault()`. Например, при обработке отправки формы можно предотвратить перезагрузку страницы, а при нажатии Enter в поле списка — стандартную отправку формы.

5. **В чем разница между `classList.add()` и `className` для работы с CSS-классами?**  
   `classList.add()` добавляет конкретный класс, не затрагивая остальные классы элемента; также доступны `remove`, `toggle` и `contains`. Присваивание `className` заменяет всю строку классов, поэтому можно случайно удалить существующие классы.

6. **Как создать новый элемент и добавить его в DOM несколькими способами? Какой способ наиболее эффективен?**  
   Элемент можно создать через `document.createElement()`, затем добавить с помощью `append`, `appendChild`, `prepend`, `before`, `after` или `insertBefore`. Для нескольких элементов удобно подготовить их в `DocumentFragment` и вставить одним действием, сокращая количество операций обновления DOM. Для текстовых данных лучше использовать `textContent`.

7. **Что такое всплытие событий и как работает метод `stopPropagation()`?**  
   При всплытии событие после обработки на целевом элементе проходит вверх по DOM-дереву к его родителям. `stopPropagation()` прекращает дальнейшее распространение события по цепочке, но не отменяет стандартное действие элемента.

8. **Как получить данные из формы и в чем разница между методами сбора form data?**  
   Можно читать значения отдельных полей через `form.elements` или свойства элементов, а также использовать `new FormData(form)`, который собирает поля формы по их атрибутам `name`. `FormData` удобно применять при отправке данных, в том числе файлов; при работе с ним значения обычно представлены строками или объектами `File`.

9. **Какие события используются для обработки ввода данных и в чем разница между `input`, `change` и `keyup`?**  
   `input` возникает при изменении значения в процессе ввода или редактирования. `change` срабатывает при подтвержденном изменении значения (момент зависит от типа элемента). `keyup` возникает при отпускании клавиши и не всегда отражает изменение значения, например при вставке мышью или некоторых способах ввода.

10. **Как оптимизировать производительность при частых манипуляциях с DOM?**  
    Следует минимизировать количество обращений и изменений DOM, объединять создание элементов во фрагменте, использовать делегирование событий, не читать layout-свойства сразу после изменений стилей без необходимости, применять `requestAnimationFrame` для визуальных обновлений и debounce/throttle для частых событий.
