# Практическая работа №11 — JavaScript: манипуляции DOM-деревом

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Используйте элементы на странице для проверки функций.
4. Нажмите «Запустить тесты» для запуска встроенных тестов.
5. Ответы на вопросы находятся в `answers.md`.

## Файлы
- `index.html` — структура интерфейса
- `styles.css` — оформление
- `dom-tasks.js` — реализация функций практической работы
- `dom-tests.js` — тесты
- `answers.md` — ответы на вопросы для самоконтроля
