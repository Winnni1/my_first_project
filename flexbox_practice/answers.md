# Ответы на вопросы для самоконтроля

## 1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?

Основное свойство — `display: flex` (или `display: inline-flex`). После его применения элемент становится **flex-контейнером**, а все его прямые дочерние элементы — **flex-элементами**. Они выстраиваются в линию вдоль главной оси (по умолчанию — горизонтально), получают возможность гибко изменять размеры и выравниваться с помощью свойств Flexbox.

## 2. В чем разница между justify-content и align-items?

- `justify-content` выравнивает flex-элементы вдоль **главной оси** (main axis). Например, при `flex-direction: row` — по горизонтали.
- `align-items` выравнивает flex-элементы вдоль **поперечной оси** (cross axis). При `flex-direction: row` — по вертикали.

**Примеры:**
- `justify-content: space-between` — распределяет элементы по горизонтали с равными промежутками между ними.
- `align-items: center` — центрирует элементы по вертикали внутри контейнера.

## 3. Что делает свойство flex-direction и какие значения может принимать?

`flex-direction` задаёт направление главной оси, вдоль которой располагаются flex-элементы. Значения:
- `row` (по умолчанию) — слева направо;
- `row-reverse` — справа налево;
- `column` — сверху вниз;
- `column-reverse` — снизу вверх.

Оно определяет, какая ось будет главной (main axis), а какая — поперечной (cross axis), и влияет на работу `justify-content` и `align-items`.

## 4. Объясните значение трех свойств в сокращенной записи flex: 1.

Запись `flex: 1` эквивалентна `flex: 1 1 0%`:
- `flex-grow: 1` — элемент может растягиваться, занимая доступное свободное пространство;
- `flex-shrink: 1` — элемент может сжиматься при нехватке места;
- `flex-basis: 0%` — базовый размер элемента до распределения свободного пространства равен нулю.

В результате все элементы с `flex: 1` делят доступное пространство поровну.

## 5. Как работает свойство flex-wrap и в каких случаях его следует использовать?

`flex-wrap` определяет, будет ли flex-контейнер переносить элементы на новую строку (или колонку), если они не помещаются. Значения:
- `nowrap` (по умолчанию) — все элементы в одну линию;
- `wrap` — перенос на следующую строку;
- `wrap-reverse` — перенос в обратном порядке.

Используется, когда нужно создать адаптивную сетку карточек, которые при уменьшении экрана переносятся на новую строку, а не сжимаются до нечитаемого размера.

## 6. Чем отличается align-content от align-items и когда применяется каждое из этих свойств?

- `align-items` выравнивает **отдельные элементы** внутри одной линии (строки/колонки) вдоль поперечной оси.
- `align-content` выравнивает **сами линии** (строки/колонки) относительно поперечной оси. Работает только при `flex-wrap: wrap` и наличии нескольких линий.

`align-items` применяется всегда, когда нужно выровнять элементы внутри контейнера. `align-content` — когда элементов больше, чем помещается в одну линию, и нужно управлять распределением этих линий.

## 7. Как свойство order влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?

`order` изменяет порядок отображения flex-элементов без изменения HTML-разметки. По умолчанию все элементы имеют `order: 0`; элементы с меньшим значением отображаются раньше.

Полезно, когда нужно:
- изменить визуальный порядок элементов на мобильных устройствах (например, вынести важный блок наверх);
- переставить карточки в галерее;
- реализовать адаптивные макеты без дублирования HTML.

## 8. Что такое "осевая линия" (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с flex-direction?

- **Main axis (главная ось)** — ось, вдоль которой располагаются flex-элементы. Её направление задаётся свойством `flex-direction`.
- **Cross axis (поперечная ось)** — ось, перпендикулярная главной.

Если `flex-direction: row`, главная ось горизонтальна, поперечная — вертикальна. Если `flex-direction: column`, главная ось вертикальна, поперечная — горизонтальна.

Свойства `justify-content` работают вдоль главной оси, а `align-items` / `align-content` — вдоль поперечной.

## 9. Как создать адаптивный макет с помощью Flexbox без использования медиа-запросов? Приведите пример.

Можно использовать `flex-wrap: wrap` вместе с гибкими базовыми размерами (`flex-basis`, `min-width`) — элементы будут переноситься на новую строку при нехватке места.

**Пример:**
```css
.container {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}

.item {
    flex: 1 1 250px; /* минимум ~250px, растягивается при возможности */
    background: #ecf0f1;
    padding: 1rem;
}
```

При широком экране элементы стоят в ряд, при сужении — переносятся на новую строку. Это адаптивность без медиа-запросов.

## 10. Какие преимущества дает использование gap вместо margins для создания промежутков между flex-элементами?

- **Чистота кода**: не нужно задавать margin каждому элементу и компенсировать отступы у первого/последнего.
- **Равномерность**: `gap` создаёт одинаковые промежутки между элементами, но не добавляет отступы по краям контейнера.
- **Работа с переносами**: при `flex-wrap: wrap` `gap` корректно задаёт отступы и по горизонтали, и по вертикали между строками.
- **Меньше конфликтов**: не нужно переопределять margin в медиа-запросах.
- **Проще поддерживать**: изменение одного значения `gap` меняет все промежутки.
