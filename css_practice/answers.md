# Ответы на вопросы для самоконтроля (Практическая работа №3)

## 1. Селектор по классу vs по ID: специфичность и повторное использование

- **Класс** имеет специфичность `0,1,0`, **ID** — `0,1,0,0` (в нотации 0-ID-класс-тег: `0,1,0` vs `0,1,0,0`, т.е. ID «весит» больше).
- Класс можно применять к **многим** элементам на странице, а ID по правилам HTML должен быть **уникальным** на странице.
- Поэтому для стилизации лучше использовать классы (переиспользуемы, ниже специфичность → проще переопределять), а ID — для якорей и точечных JS-хуков.

## 2. Как работает каскад CSS

При конфликте правил браузер выбирает победителя в следующем порядке:

1. **Важность**: `!important` важнее обычных объявлений (но user styles с `!important` важнее авторских).
2. **Источник**: user-agent < user < author (авторские стили — наши).
3. **Специфичность селектора** (слева направо: inline > ID > классы/атрибуты/псевдоклассы > теги/псевдоэлементы).
4. **Порядок объявления**: при равной специфичности побеждает то правило, что объявлено **ниже** в файле (или в подключённом позже файле).
5. **Наследование** — только для свойств, которые наследуются, и применяется, если у элемента нет своего значения.

## 3. Расчёт специфичности

| Селектор | Специфичность (a,b,c) |
|---|---|
| `ul li.important` | `0,1,2` (0 ID, 1 класс, 2 тега) |
| `#site-title` | `1,0,0` (1 ID, 0 классов, 0 тегов) |
| `.content > .featured-post` | `0,2,0` (0 ID, 2 класса, 0 тегов) |

## 4. Наследуемые и ненаследуемые свойства

**Наследуются по умолчанию (3 примера):**
- `color`
- `font-family`
- `line-height`
(также `font-size`, `font-weight`, `font-style`, `text-align`, `visibility`, `cursor` и др.)

**Не наследуются (3 примера):**
- `margin`
- `padding`
- `border`
(также `background`, `width`, `height`, `display`, `position`, `box-sizing` и др.)

## 5. `>` (дочерний) vs пробел (потомок)

- `.content > article` выбирает **только непосредственных детей** элемента `.content`.
- `.content article` (через пробел) выбирает **всех потомков** на любой глубине вложенности.

## 6. Псевдоклассы `:hover` и `:nth-child()`

- `:hover` — стиль элемента при наведении курсора. Применяется для кнопок, ссылок, пунктов меню, подсветки строк таблицы, карточек.
- `:nth-child(n)` — выбирает элемент по его позиции среди братьев (например, `odd`/`even`, `3n`, `2n+1`). Применяется для «зебры» в таблицах/списках, выделения первого/последнего элемента, скрытия каждого N-го.

## 7. `!important`

Правило `!important` повышает приоритет объявления выше всех обычных правил (в том числе с большей специфичностью). Использовать с осторожностью, потому что:
- ломает естественный каскад и делает код труднопредсказуемым;
- затрудняет переопределение стилей (например, при интеграции сторонних библиотек);
- усложняет поддержку проекта.

## 8. Псевдоэлементы `::before` и `::after`

Создают «виртуальные» дочерние элементы до/после содержимого элемента. Позволяют добавлять **декоративный контент** без изменения HTML: иконки, стрелки, маркеры, разделители, кавычки, счётчики, всплывающие подсказки. Работают при наличии `content` (может быть пустым `""`, текстом, `attr(...)`, `url(...)`, `counter(...)`).

## 9. Порядок применения правил при одинаковой специфичности

Побеждает **более позднее** по порядку объявление (кто ниже в каскадном списке / подключён позже). Если один и тот же селектор объявлен дважды — сработает последнее объявление.

## 10. Инструменты разработчика

DevTools браузера (F12) позволяют:
- видеть **применённые** стили и **перечёркнутые** (переопределённые) правила;
- видеть **источник правила** (файл и строка);
- **переключать/редактировать** свойства и значения в реальном времени;
- проверять **наследование** (вкладка Computed / Inherited);
- анализировать **специфичность** и порядок каскада;
- проверять адаптивность через режим устройства;
- отлаживать анимации и переходы.
