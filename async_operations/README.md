# Практическая работа №13 — JavaScript: асинхронные операции

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере (лучше через Live Server).
3. Нажимайте кнопки каждого раздела.
4. Для тестов откройте DevTools (F12) → Console. Тесты запускаются автоматически.

## Содержимое
- `index.html` — интерфейс семи задач.
- `styles.css` — оформление.
- `async-tasks.js` — реализация функций: Promise, async/await, fetch API, таймеры, обработка ошибок, параллельность, последовательные запросы, симуляция загрузки, кэш.
- `async-tests.js` — самостоятельные асинхронные тесты.
- `answers.md` — ответы на вопросы самоконтроля.

## Примечание
Запросы к JSONPlaceholder требуют подключения к интернету. API — учебный сервис, POST-запрос не сохраняет данные постоянно. Ошибка API проверяется запросом к заведомо неверному endpoint.
