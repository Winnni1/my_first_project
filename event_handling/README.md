# Практическая работа №12 — JavaScript: обработка событий

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Проверяйте интерактивные блоки на странице.
4. Кнопка «Запустить тесты» выполняет тесты из `events-tests.js`.
5. Ответы на вопросы находятся в `answers.md`.

## Содержимое
- `index.html` — HTML-страница со всеми 7 задачами
- `styles.css` — оформление и анимации
- `events-tasks.js` — реализации обработчиков
- `events-tests.js` — тесты
- `answers.md` — ответы на вопросы

Примечание: загрузка изображения использует внешний URL и требует интернет-подключения. Кнопка ошибки проверяет обработку несуществующего ресурса.
